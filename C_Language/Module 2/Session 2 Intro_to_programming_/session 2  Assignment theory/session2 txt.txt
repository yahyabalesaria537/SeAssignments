Q.1 install GCC on your computer and verify the installation by running gcc --version in your terminal or command prompt.
ANS: Install GCC and verify installation
Steps:
1. Install GCC on the computer.
2. Open command prompt (or terminal).
3. Type the following command:
 gcc --version
4. Press enter.
5. if the GCC version is displayed, the installation is successful.
Example Output:
gcc (MinGW.org GCC) 6.x.x
copyright (c) free software foundation, inc.
Result:GCC was successfully installed and verified using the gcc --version command.
