Q.1 Write the git command for each: initialize a repo, stage all files, commit with a message, push to remote, pull latest changes.
ANS-Here are the basic git commands for each task:
</> Bash
# Initialize a new get repository
git init 

# Stage all files
git add .

# Commit with a message
git commit -m "Your commit message"

# Push to the remote repository (main branch)
git push origin main

# Pull the latest changes from the remote repository
git pull origin main

Q.2 What is the difference between git fetch and git pull? Answer in 2 lines.
Difference between git fetch and git pull (2 lines)
1.git fetch downloads the latest changes from the remote repository but does not merge them into your current branch.
2.git pull downloads the latest changes and automatically merges them into your current branch.

Assignment: Create a new GitHub Repository and Push a Text file
1.Create a new repository on GitHub (e.g., git -assignment).
2.Create a text file named hello.txt and write:
   Hello, GitHub!
   This is my first git assignment.
3.Open Git Bash in the project folder and run:
   git init
   git add .
   git commit -m "Add hello.txt"
   git branch -m main
   git remote add origin https://github.com/USERNAME/git-assigment.git
   git push -u origin main
4.Repository Link (Example Format):
  https://github.com/USERNAME/git -assignment. Git
  Replace USERNAME with your GitHub username.

Q.4 What is the difference between a Fork and a Pull Request? Answer in 2 lines.
Difference between a fork and a pull request (2 lines):
1.Fork: A fork creates a copy of someone else's GitHub repository in your own GitHub account.
2.Pull Request: A pull request is a request to merge your changes from your repository or branch inti the original repository.

Q.5 Create a new branch named feature-test, make one commit on it, and merge it back to the main branch. Write the commands you used.
Commands to create a branch, make a commit, and merge it into the main branch:

git checkout -b feature-test
echo "feature added" > feature.txt 
git add .
git commit -m "add feature.txt"
git checkout main
git merge feature-test.
